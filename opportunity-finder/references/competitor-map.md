# Competitor Map — Opportunity Discovery / Validation

This map prevents Opportunity Finder from rebuilding mature categories.

## Category A — Pain databases / signal mining platforms

Examples: BigIdeasDB, PainHunt, PainSignal, MonetScope.

Common strengths:

- large historical complaint/review corpora;
- multi-source pain clustering;
- severity / WTP / competition scoring;
- opportunity feeds and filters;
- competitor-gap reports;
- ongoing radar/monitoring;
- some provide MCP access, revenue intelligence, or build tooling.

**Do not compete by building another giant complaint database.** Use public/live sources and external intelligence when available.

## Category B — Idea validators

Examples: TweakIdea, Venture Analyst, similar Claude/Codex skills.

Common strengths:

- take a user-supplied idea;
- research competitors and demand;
- score multiple dimensions;
- output GO/PIVOT/STOP or equivalent;
- may run parallel evaluators and produce shareable reports.

**Opportunity Finder's main job is different:** discover what is worth shipping *before* the user has an idea, with a Quick-Commerce constraint.

## Category C — Generic idea generators

These generate lists from prompts or trend summaries.

Treat this category as commoditized. Do not copy it.

## Opportunity Finder's intended wedge

1. Focus on AI power users and Agent-native second-order pain.
2. Study high-install/high-growth Skills as market behavior, then search one job beyond them.
3. Normalize install signals instead of blindly ranking by installs.
4. Optimize for <1 workday build, low seller marginal cost, and natural Skill/plugin distribution.
5. Include seller economics, support debt, BYOK/runtime-cost owner, and portfolio role.
6. Prefer current windows (24h / 7d / 30d) over giant TAM.
7. Try to kill opportunities before recommending them.
8. Output a launch hypothesis, not a generic business plan.
